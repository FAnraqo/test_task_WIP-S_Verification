## Инструкция по сборке и запуску

Для запуска симуляции и тестирования используются следующие команды:

* `make run_test` — запуск одного базового теста (по умолчанию с рандомными числами).
* `make run_regression` — запуск полного набора тестов (рандомные, равные, минимальные, максимальные значения) и генерация отчета по кодовому покрытию.

*Примечание: команды выполняются из директории `sim/`.*

## Результаты верификации

В ходе тестирования с помощью разработанного UVM-окружения была обнаружена логическая ошибка в RTL-модуле `data_comparator.sv`. 

**Описание ошибки:**
При отсутствии валидности на входе (`valid_i = 0`) сдвиговый регистр не очищает свой младший бит. Из-за этого происходит "залипание" единицы в конвейере, что приводит к ошибочной выдаче `valid_o = 1` на выходе даже тогда, когда новые данные не поступают.

**Решение:**
Для устранения ошибки не хватает добавления ветки `else` с принудительным сбросом нулевого бита в блоке `always_ff`:

```systemverilog
    always_ff @ (posedge clk) begin
        if (!rstn) begin
            valid_internal <= '0;
        end
        else begin
            if (valid_i) begin
                valid_internal <= '1;
            end else begin
                // ИСПРАВЛЕНИЕ: принудительно сбрасываем бит при valid_i == 0
                valid_internal <= '0;
            end
            valid_internal[5:1] <= valid_internal[4:0];
        end
    end
